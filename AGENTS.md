# Portfolio editing instructions

- Work on this existing portfolio. Keep user-facing content and illustration paths in `portfolio-data.json`.
- Before a major design or structural change, commit the current working version, including its referenced assets, and push it to `origin` before editing. The user explicitly requires GitHub checkpoints so earlier designs remain recoverable.
- After completing and checking a major change, commit and push the result. Write a clear commit title and body describing the actual changes.
- Preserve unrelated work. Do not reset or overwrite changes to recover an older design; use Git history and a focused revert when requested.
- Check the result in the local preview, including desktop and mobile layouts. Keep light/dark switching, project/work detail dialogs, and downloads functional.
